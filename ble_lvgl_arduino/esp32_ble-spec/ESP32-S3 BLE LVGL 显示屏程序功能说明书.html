ESP32-S3 BLE LVGL 显示屏程序功能说明书

穿戴康复外骨骼机械手 — 智能显示屏控制系统

硬件平台: ESP32-S3| UI框架: LVGL v8| 通信: BLE 5.0 (NimBLE)| 版本: 1.0| 日期: 2026-08-05

01项目概述

本项目是一套基于 ESP32-S3 微控制器的嵌入式显示控制系统，专为穿戴康复外骨骼机械手设计。系统通过 BLE 无线接收肌电传感器/控制器发出的 11 路通道数据，经阈值判断后驱动 6 路舵机 PWM 输出，实现手指的屈伸运动控制。同时提供触摸屏 GUI 界面，支持设备扫描连接、实时数据监控、PWM 输出调节、以及离线手势自主训练等功能。

核心功能
BLE 设备扫描与连接、11 通道实时数据接收与显示、6 路 PWM 舵机驱动、急停与单通道暂停控制
训练模式
12 种预设手势图案（数字 1-8/10、OK、点赞、爱心），离线自主训练无需 BLE 连接
显示规格
SH8601 AMOLED 屏 280×456 像素、FT3168 电容触摸、SPI + I2C 接口
安全机制
全局急停按钮（所有通道强制 1500us 中位）、单通道手动覆盖、优先级分层控制

系统定位

本显示屏作为外骨骼机械手的人机交互终端，承担三大角色：

  • 通信枢纽 — 通过 BLE 与上位机/传感器节点建立 GATT 连接，接收实时肌电信号
  • 控制核心 — 将传感器数据按阈值映射为舵机 PWM 脉宽，驱动 6 路手指运动
  • 交互界面 — 提供触摸屏 GUI，实时显示数据、PWM 状态，支持手动干预与训练

02硬件架构

主控芯片

采用 ESP32-S3 双核 Xtensa LX7 处理器，集成 2.4GHz Wi-Fi + BLE 5.0 射频，支持 PSRAM。本项目中关闭 Wi-Fi 以避免与 BLE 共享射频造成干扰，专注 BLE 通信。

固件基于 Arduino-ESP32 3.x 框架开发，使用 FreeRTOS 多任务调度。LVGL v8 负责图形界面渲染，NimBLE 协议栈负责 BLE 通信。

初始化流程

系统启动时按以下步骤依次初始化各模块：

  1. STEP 1 — 触摸驱动：初始化 FT3168 I2C 触摸控制器
  2. STEP 2 — LCD + LVGL：初始化 SH8601 AMOLED 面板、挂载 LVGL 显示驱动与触摸驱动、启动 LVGL 定时器任务
  3. STEP 3 — BLE 管理器：关闭 Wi-Fi 避免 RF 干扰、初始化 NimBLE 设备、创建扫描器与数据接收队列、注册回调
  4. STEP 4 — UI 界面：创建 6 个屏幕对象、绑定边缘滑动事件、加载主屏
  5. STEP 5 — PWM 输出：初始化 6 路 LEDC 通道（50Hz / 16bit），默认输出低脉宽避免舵机抖动

04软件界面说明

系统共有 6 个屏幕界面，通过触摸点击按钮或屏幕边缘滑动切换。屏幕间导航关系如下：

边缘滑动切换机制

滑动规则：主屏 ↔ 数据屏 ↔ PWM 屏 构成线性顺序。左边缘 80px 内右滑 → 上一屏；右边缘 80px 内左滑 → 下一屏。手势屏不在此线性顺序中，由主屏"TRAINING"按钮进入，右边缘左滑返回主屏。滑动动画 300ms，防抖间隔 400ms。

4.1 主屏 — 模式选择 (Main Screen)

系统启动后的默认界面，提供两种工作模式入口。点击"SCAN"进入 BLE 设备扫描流程，点击"TRAINING"进入离线手势训练模式。

主屏 — Select Mode
两个蓝色按钮：SCAN（BLE 扫描）/ TRAINING（手势训练）

界面元素

  • SCAN 按钮：关闭手势模式 → 切换到设备列表屏 → 启动 BLE 扫描（1 秒）
  • TRAINING 按钮：开启手势模式（PWM 直接控制，忽略 BLE 输入） → 切换到手势屏
  • 状态标签：底部显示当前 BLE 状态（Ready / Scanning... / Disconnected 等）

4.2 设备列表屏 — 设备扫描 (Device List Screen)

显示 BLE 扫描到的设备列表，按 RSSI 信号强度从高到低排序。支持自定义设备标识（UUID+SN）去重。

设备列表屏 — Devices
按 RSSI 排序，选中项蓝底白字，底部 Connect 按钮

扫描特性

  • 扫描时长：1 秒主动扫描（setActiveScan=true），100% 占空比
  • 去重策略：带自定义厂商 ID（0xFF00）的设备按 UUID+SN 去重；否则按 MAC 去重
  • 排序：扫描结束后按 RSSI 降序排列（信号强 → 弱）
  • 显示信息：设备名 + UUID/SN（或 MAC）+ RSSI
  • 最大数量：20 台设备（BLE_SCAN_RESULT_MAX）

4.3 UUID 设置屏 — GATT 配置 (UUID Config Screen)

连接前配置目标设备的 GATT Service / Notify / Write 特征 UUID。内置十六进制键盘（0-F），默认值为 BLE 串口模块常用配置 FFE0/FFE2/FFE1。

UUID 设置屏 — UUID Config
3 个 UUID 输入框 + 十六进制键盘 + Cancel/Connect

UUID 配置说明

  • 默认值：Service=FFE0, Notify=FFE2, Write=FFE1（BLE 串口模块通用配置）
  • 支持格式：16 位（FFE0）、32 位（0000FFE0）、128 位完整 UUID，NimBLE 自动扩展比较
  • 激活指示：当前输入字段蓝色边框高亮，其余灰色边框
  • 键盘：4×5 按钮矩阵，DEL 退格 / CLR 清空，各跨 2 列

4.4 数据屏 — 实时数据监控 (BLE Data Screen)

BLE 连接成功后自动切换到此屏，实时显示 11 通道传感器数据和最新原始帧。以 ~20Hz 频率刷新（50ms 主循环周期）。

数据屏 — BLE Data
11 通道数值网格（2 列）+ 原始帧 + Disconnect/Clear

数据格式

BLE Notify 接收的原始数据帧格式为：

1800,1600,0920,0000,2000,1500,1850,0000,0650,0950,0000;
  • 帧结构：11 个数值以逗号分隔，以分号 ; 结尾
  • 帧重组：BLE 单次 Notify 最多 20 字节（MTU=23），一帧约 53 字节会被拆分，按 ; 拼接为完整帧
  • 解析：ble_manager_parse_frame() 容错解析，跳过非数字前导字符，支持负号与前导零
  • 显示：4 位零填充格式（如 0920），蓝色字体，2 列 6 行网格布局

4.5 PWM 输出屏 — 舵机控制 (PWM Output Screen)

显示 6 路 PWM 通道的输入值与输出脉宽，支持单通道暂停（覆盖）和全局急停。从数据屏右边缘左滑进入。

PWM 输出屏 — PWM Output
6 通道输入/输出显示 + 急停按钮 + 覆盖高亮（Ch3 蓝框）

PWM 屏交互

  • 通道格子：点击切换手动覆盖（输出 1500us 中位），蓝框边框高亮表示已覆盖
  • 输出颜色：绿色 = 2000/1750us（高）；蓝色 = 1000/1400us（低）；灰色 = 1500us（暂停）
  • E-STOP 按钮：红色大按钮，点击后所有通道强制 1500us，按钮变为"Resume"深红+黄边
  • Disconnect：断开 BLE 连接返回主屏
  • Clear All：清空 PWM 显示（不清除覆盖/急停状态）

4.6 手势屏 — 自主训练 (Gesture Screen)

离线手势训练模式，提供 12 种预设手势图案。点击任一手势，系统直接输出对应的 6 路 PWM 脉宽，无需 BLE 连接。

05数据通信流程

BLE 通信链路

连接重试策略

由于 BLE 设备可能使用随机 MAC（RPA），连接过程采用多策略重试机制：

  1. 尝试 1：使用原始扫描地址（含字节序反转）
  2. 尝试 2：1.5 秒快速重扫获取最新 MAC → 重试
  3. 尝试 3：强制 addr_type=0（public）重试
  4. 尝试 4：使用原始 LSB-first 字节（不反转）重试
  5. 尝试 5：原始 LSB-first + type=0 最终兜底

帧重组机制

关键设计：BLE Notify 在 MTU=23 时单次最多传输 20 字节，而一帧完整数据（11 个数值 + 逗号 + 分号）约 53 字节，会被拆分为 3 次 Notify。系统在 ble_manager_process_data() 中维护 128 字节帧缓冲区，逐字符拼接，遇到帧尾 ';' 时输出完整帧交给上层解析。缓冲区溢出时丢弃半帧重新同步。

06PWM 控制逻辑

输出映射规则

6 路 PWM 通道的输出脉宽由 BLE 输入值按阈值映射决定，CH6 由 CH1 输入值派生：

通道引脚输入来源阈值判断高输出低输出默认值
CH1GPIO3values[0]> 0650 ?2000us1000us1000us
CH2GPIO5values[1]> 0650 ?2000us1000us1000us
CH3GPIO6values[2]> 0650 ?2000us1000us1000us
CH4GPIO7values[3]> 0650 ?2000us1000us1000us
CH5GPIO8values[4]> 0650 ?2000us1000us1000us
CH6GPIO2values[0] (CH1输入值)> 0650 ?1750us1400us1400us

CH6 特殊说明：CH6 的输出基于 CH1 的输入值（values[0]）而非输出值。这意味着点击 CH1 格子启用覆盖时，CH1 输出变为 1500us，但 CH6 仍根据 CH1 的原始 BLE 输入值正常映射，不受覆盖影响。

控制优先级

PWM 输出遵循严格的优先级层次，高优先级覆盖低优先级：

PWM 硬件参数

  • 频率：50Hz（周期 20000us），标准舵机/ESC PWM 频率
  • 分辨率：16bit（65536 级），1us ≈ 3.2768 ticks
  • 脉宽范围：1000~2000us（标准舵机控制范围）
  • 优化：仅在脉宽变化时写 LEDC 寄存器，减少硬件访问
